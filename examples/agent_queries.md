# Example agent queries

Generated by `uv run python scripts/mcp_demo.py`, which launches the MCP server over **stdio** and calls its tools exactly as an agent would. Outputs below are the actual responses from the real Florida ACS data in `data/census.duckdb` (regenerate after re-ingesting). Current data: ACS 5-year 2019 and 2024, loaded with `--source summary_file` (official Census ACS Summary File) because the API key was not accepted at build time.

Tools advertised by the server: `list_tables`, `describe_table`, `run_query`, `list_metrics`, `get_metric`
